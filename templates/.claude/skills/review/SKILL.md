# /review - Code Review Skill

## Usage

- `/review` - リポジトリ全体をレビュー
- `/review <commit-hash>` - 指定コミットの変更をレビュー
- `/review <commit-hash1> <commit-hash2> ...` - 複数コミットの変更をレビュー
- `/review <commit-hash1>..<commit-hash2>` - コミット範囲の変更をレビュー

## Instructions

引数に応じてレビュー対象を決定する。

### 引数なし（リポジトリ全体レビュー）

1. リポジトリ全体の構造とファイルを探索する
2. 以下の観点でレビューする：
   - ディレクトリ構成・ファイル構成の妥当性
   - 設定ファイル間の整合性（バージョン、パスなど）
   - 不要なファイルやコメントアウトの残骸
   - セキュリティ上の懸念（秘密情報の混入など）
   - 改善提案

### コミット指定あり

1. 指定されたコミットの差分を `git show` または `git diff` で取得する
2. 以下の観点でレビューする：
   - 変更内容の正確性
   - コミットメッセージと変更内容の一致
   - 既存コードとの整合性
   - バグやタイポの有無
   - 改善提案

## Output Format

レビュー結果は以下の形式で出力する：

### 良い点
- 箇条書きで列挙

### 指摘事項
- 重要度（高/中/低）を付与
- 具体的なファイルパスと行番号を示す
- 修正案がある場合は提示する

### 改善提案
- 必須ではないが、あると良い改善を箇条書きで列挙
